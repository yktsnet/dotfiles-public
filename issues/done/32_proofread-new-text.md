### .claude/agents/jp-proofreader.md

「直す範囲」の「既定は keep で、同じ変換を全箇所へ一律に当てない」を、次の2項目に置き換える。

```
- 渡された範囲の行は、書き手がそのブランチで書いた文である。規範をすべて当てて直し、keep を既定にしない。
  範囲が渡されず、ファイルのパスだけのときは既存の文書として扱い、既定は keep で、同じ変換を全箇所へ
  一律に当てない
- 語が読み手に通じるかも見る。内輪の呼び名や比喩が術語になっていたら、範囲の行なら中身で書き直す
```

「報告」の2項目目を「直さずに報告に回した箇所と、その理由。自分で残してよいと判断した箇所も省かず、行と理由を返す」にする。

### .claude/skills/jp-writing/SKILL.md

- 「リライトの作法」の冒頭「デフォルトは keep。」の直後に「ただし、これは他人が書いた文や、今回の作業より前からある文に当てる。自分がいま書いた文は、規範をすべて当てて直す。」を足す
- 「視点と語り」の「術語・固有名を導入したら、以後はその語で通す。」の次に、「内輪の呼び名や比喩を術語にしない。その語だけを見て、初めて読む人が中身を言えないなら、中身をそのまま書く。術語として入れるなら、初めて出るところで何を指すかを書く。」を足す

- 「校正役の直しを読み、…」の後に「校正役が直さずに報告へ回した点は、書き手が一人で退けない。直すか残すかを user に見せて決める」
