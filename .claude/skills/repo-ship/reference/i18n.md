# i18n：英語版の README を作る

既存の日本語 README.md を原本として英語版を生成/更新する。重要な文書を選んだときは、その文書も同じ手順で `*.en.md` を対で作る。

## 対象の決定

1. 段の名前に続けてパスが渡されていればそのディレクトリの README を対象にする
2. カレントディレクトリに `README.md` があればそれを対象にする
3. どちらもなければ、1階層下のサブディレクトリを走査し `README.md` を持つディレクトリを列挙する。対象一覧をユーザーに提示し、確認を得てから一括処理を開始する。

一括処理の場合、各ディレクトリに対して以下の手順を繰り返す。

## 訳す範囲を決める

英語版を作るのは、トップの README と重要な文書だけにする。重要な文書は、トップの README から直接リンクしていて、リポの中身の核になるもの（評価基準や仕様の正本、使う人が最初に読む導入の手順）を指す。下位のディレクトリの README、運用・設計判断・内部構造の文書は訳さない。訳すほど、日本語版を直すたびに英語版も追いかける手間が増える。

重要な文書の候補をトップの README のリンクから拾い、AskUserQuestion で選んでもらう。英語版から、英語版の無い文書へリンクするときは、その先が日本語であることを添える。

## 手順（ディレクトリごと）

### 1. README.md を読む

対象ディレクトリの `README.md` と、範囲に含めると決めた文書だけを読み込む。関連する文書も訳すなら、言語リンク・英語版の作り方・翻訳ルールは README と同じものを当て、英語版どうしのリンクは `*.en.md` へ向ける。CLAUDE.md・context/・skills/ など他のファイルは読まない。翻訳に必要な情報は README.md の中に全てある。

### 2. 言語リンクの挿入（未挿入の場合のみ）

README.md の先頭（H1 の直前）に以下を挿入する。既に同等のリンク行があればスキップ。

```
[🇯🇵 日本語](README.md) | [🇬🇧 English](README.en.md)
```

### 3. 英語版の生成/更新

- `README.en.md` が存在しない場合: README.md の内容を自然な英語に翻訳して新規作成
- `README.en.md` が既に存在する場合: README.md の差分を反映して更新（英語版独自の加筆があれば保持）
- 英語版の先頭にも同じ言語リンクを挿入（リンク先は逆）:

```
[🇯🇵 日本語](README.md) | [🇬🇧 English](README.en.md)
```

### 4. 翻訳ルール

- 技術用語・コマンド・コードブロック・パス・URL はそのまま残す
- Mermaid 図のノードラベルは英訳する
- テーブル構造・バッジ・リンクは維持
- 見出しレベル・構成順序は原本と一致させる

### 5. 出して止まる

変更をワーキングツリーに残し、追加/更新した内容を要約して報告する。
一括処理の場合は処理したディレクトリ一覧と各ステータス（新規作成/更新/スキップ）を表示する。
