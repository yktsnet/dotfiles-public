# opinion チェックリスト

## 項目

| 質問 | 意図 | 根拠 |
|---|---|---|
| 誰の、どの判断に引っかかっているか | 相手と、何を否定されたと受け取られそうかを見極める | 相手は反対意見の中身より、自分の案を否定されたことに身構える |
| その判断の背景を知っているか | 知らない事情があれば、反対より先に聞く | 判断する側は、上や取引先の事情を抱えていることが多い。聞けば「動かせないならどこを削るか」の話に変わる |
| 相手がいちばん守りたいものは何か | 共通の目的から話を始める | 組織の目標（収益・顧客満足など）に結びついた主張は、相手自身の問題として受け取られやすい |
| いつ・どこで伝えるか | 決まる前に、1対1で伝える | 人前で否定されると引けなくなる。決まってからでは遅く、動き出してからはさらに遅い |
| 懸念・根拠・代案は何か | 立場ではなく、判断に使える材料を渡す | 材料がそろうと、相手は「やるかどうか」ではなく「どれを選ぶか」で考えられる。代案が無くても、早く知らせること自体に価値がある |
| 自分の見立てにどれくらい自信があるか | 言い切るか、懸念として出すかを決める | 自分が正しいとも限らない。外れたときに認める人ほど、次も聞いてもらえる |
| 通らなかったら従えるか | 決めるのは相手。従えない種類なら別の経路を考える | 反対することと、決まったらやり切ることは両立する。責任を負う人が決める |
| 伝える手段は何か | 台本にするか文面にするかを決める | なし |

聞き方の例：

- 背景：「この締め切りの決め手を知っておきたいです。こちらの段取りを組むのに使いたくて」。
  「なんで」で始めると理由の弁明を求める形になるので避け、聞く目的を添える
- 目的：「今回は締め切りと品質、どちらを優先する想定ですか」

## 言い換え

| 避ける | 言い換え |
|---|---|
| なんでこうしたんですか | どういう経緯でこう決まったか教えてください |
| 普通は〜ですよね | 別のプロジェクトでは〜で進めた例があります |
| みんなそう言ってます | 私としては〜が引っかかっています |
| それは無理です | 今の人数だと〜が厳しいです。〜を外せば間に合います |
| だから言ったじゃないですか | 前に挙げていた〜が実際に起きました。影響は〜です。対応は〜でどうでしょう |

多数派の圧や感情ではなく、事実と条件で話すための言い換えである。
